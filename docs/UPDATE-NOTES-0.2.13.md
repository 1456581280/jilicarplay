# DiPlay 0.2.13

- 合并上游 0.2.13 更新，改善无线连接发现、等待画面的昼夜显示，并增加繁体中文支持。
- 改善星越 L（KX11）原车热点的兼容性，补充连接条件与连接阶段诊断。
- 新增导航投屏编辑器，可调整导航提示的位置和大小，并按需添加车速、转速、灯光和时钟。
- 支持通过三指上滑切换导航提示投屏，保留原有三指下滑操作。
- 新增独立车桥客户端，支持导入车辆扫描报告和选择车型预设；车辆数据及方向盘按键需要配套车桥与车机支持。
- 改善方向盘按键的接入与事件占用处理；实际支持情况取决于车机提供的接口与权限。

适用于 Android 9 及以上车机。仪表和 HUD 功能需要车机开放相应显示与悬浮窗能力。当前导航投屏显示导航提示，完整地图投屏仍在开发中。本次版本尚需实车验证。
