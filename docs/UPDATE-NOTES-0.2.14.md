# DiPlay 0.2.14

- 更新无线、USB、热点和蓝牙连接流程，改善老车机的连接兼容性与连接中断处理。
- 声音设置精简为导航、媒体两组。导航独立输出，通话、语音助手、铃声、微信及音乐统一使用媒体通道，保留数值调节和设备选择。
- 新增“原厂输出 / 蓝牙输出”。蓝牙输出保留车机蓝牙音乐，播放时自动避免重复音乐；导航、通话和语音继续正常播放。无法确认蓝牙播放时，保留 CarPlay 声音。
- 车辆属性支持一键扫描、分析、提取、应用和保存，保留已有单位及校准配置。
- 扫描报告直接保存到“下载/DiPlay”，无需文件保存或分享工具；Android 9 首次使用需要存储权限。
- 扫描报告与运行日志分别保存和上传，新增车型、车机硬件、系统、应用及车辆数据桥版本信息。
- 扫描报告自动上传云端，支持最高 10 MB；断网后自动重试，也可手动重新上传，结果页显示上传状态。
- “隐藏顶部状态栏”和底部导航栏设置覆盖主页、设置、扫描与 CarPlay 页面。
- 改进方控接入与按键接管，减少切歌时原生音乐同时响应；请同时更新车辆数据桥至 0.11.24。
- 设置列表直接提供“方控测试”和“车辅属性扫描”。
- 保留导航优先的投屏编辑器、车辆数据、完整地图投屏、三指切换，以及音量按键或旋钮缩放。

最低支持 Android 9。连接、声音和车辆显示效果仍需实际车型确认。
