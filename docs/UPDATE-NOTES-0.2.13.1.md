# DiPlay 0.2.13.1

- 调整无线、USB、热点和蓝牙连接流程，采用此前车型反馈稳定的连接方案。
- “隐藏顶部状态栏”也可用于 DiPlay 主页和设置页面，切换后立即生效。
- 改善 CarPlay 与车机蓝牙音乐的切换，降低同时播放的情况；结束后尝试恢复原有音乐连接。
- 导航提示会压低媒体音量，通话和语音助手优先；改善切换后的声音恢复。
- 媒体、导航、通话、语音助手及铃声可分别选择输出设备，通话和语音助手可分别选择麦克风，保留设备数值输入。
- 音频设备断开时回退到系统通道，重新连接后重新应用已保存的设备选择。
- 增加完整导航地图投屏、地图区域调整及音量按键或旋钮缩放，适用于支持相应屏幕和按键接入的车型。
- 支持三指切换地图投屏，改善不同屏幕尺寸和分辨率的显示适配。
- 兼容车桥可在地图实际显示后切换原车仪表导航模式，结束后恢复原模式。

最低支持 Android 9。蓝牙切换、音频设备和仪表投屏效果取决于车机固件；本版仍需在实际车辆上确认。
