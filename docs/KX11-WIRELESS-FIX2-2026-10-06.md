# KX11 多网络连接修复包

版本：`0.2.12-kx11-wireless-fix2`，versionCode 33。新增连接功能标记：carlito。

## 实现范围

- 复用 Android 普通热点、ECARX WifiAp / Wifi6Ap 读取。Bootstrap 的热点凭据与并行监听候选分别管理，未硬编码手机地址、网关或接口名称。
- 枚举本地私有 IPv4 和有接口作用域的 IPv6。加入有私有 IPv4 的以太网、桥接和 VLAN 通路；排除可识别的蜂窝、VPN 和占位接口。
- 同一端口监听多个本地地址。次要候选绑定失败记录原因，不阻止其他地址启动。只有实际绑定成功的地址参与服务发现。
- 每个源地址独立运行 Bonjour。发现结果按源地址、IPv6 scope、手机地址和端口去重；主动连接使用发现所在接口。框架提供 Network 时只绑定主动探测 socket，不改变进程默认网络。
- 每轮探测让出队列，最多三次，避免一个失效接口连续耗尽所有发现机会。
- 网络回调结合两秒网卡检查。接口变化时增减监听与服务通告，保持已有会话；generation / listener identity 防止旧回调修改新会话。
- 只有建立协议会话后占用无线媒体。时间同步、保活、事件以及已有媒体通道使用实际控制连接的本机地址。
- 保留首个 TCP 超时，并增加 TCP 到达后的协议启动超时。无 TCP 的失败接口短期记录，后续重试优先剩余候选；已有明确 ECARX 客户端路由时保留路由证据。沿用 UI 的有限重试预算。
- USB 与热点独立。新增未过滤设备枚举、VID/PID、配置数、匹配结果、授权及插拔事件，不改变 USBMUX 的配置和协议。

## 诊断报告

`LOCAL_NETWORK` 专用记录保留 RFC1918 IPv4，用于核对车机接口、手机和子网。公网 IP、MAC、IPv6 字面量、密钥、密码、协议内容仍脱敏。IPv6 的接口名、接口索引和 scope 留在报告中。

记录包含客户端地址、路由推导结果、本机接口地址/前缀、监听成功或异常类型、Bonjour 发布/发现/探测、接入和协议建立。`publication ready` 表示库注册完成，不代表已抓到网络上的实际组播数据包。

普通界面只新增清楚的启动失败提示；技术信息沿用已有开发者诊断入口。

## 边界和待实车确认

- Android 应用不可见的热点、无返回路由、厂商隔离或防火墙不能由增加 socket 自动绕过；日志提供区分这些情况所需的接口证据，但不能仅凭无接收数据断言具体阻断机制。
- 不猜测不可读的 ECARX 热点名称或密码。系统配置与用户保存配置的匹配关系单独记录；用户明确选择手动模式且 ECARX 热点有活动证据时，另一套普通热点保存的配置不会覆盖用户输入。
- 该包是基于 fix1 的修复分支，GD / DiPlay 的其他模块开发仍保持已保存状态。
- 此请求未运行单元测试或实车测试。构建结果、安装包签名、认证材料及版本信息由交付记录单独确认。
