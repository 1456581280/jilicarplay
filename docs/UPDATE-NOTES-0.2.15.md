# JiliCarPlay 0.2.15 正式版

- 首页改为素材包中的深蓝、暖色风格；原生布局适配横屏、竖屏、短屏和系统大字体。
- 新增 GitHub 正式版本检查、更新提示、用户确认下载和 Android 安装确认。
- 首页提供仓库入口，点击版本号可手动检查更新。
- 继续保留无车辆报告/方控配置上传的改动；原有连接逻辑保留。

包名 `com.shihab.diplay`，版本码 41。沿用 0.2.14-local.1 的本地签名，可覆盖该版本并保留数据；不能覆盖作者签名的原安装。
仓库需由所有者改为公开，车机还需能访问 GitHub，自动更新才可获取版本及安装包。本次不更改仓库可见性。

更新发布规则见 [更新说明](GITHUB-UPDATES.md)。

- 新增“设置 → 自定义 HTML 首页”：粘贴、预览、保存、恢复默认，以及完整示例和 AI 提示词/原生功能入口。
- 项目源码显示原始开源项目、上游二次开发和本项目三个指定 GitHub 地址。
- HTML 首页使用本机文件，阻止网络/文件访问；只有用户点击的指定入口可调用现有功能。使用说明见 [HTML-HOME.md](HTML-HOME.md)。
