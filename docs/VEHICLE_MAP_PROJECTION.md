# 地图投屏与屏幕适配

## 主屏

主屏按当前窗口尺寸显示 CarPlay，保持画面比例。全屏、分屏或横竖屏变化时重新计算显示区域；需要改变手机输出尺寸时，会重新建立连接。

## 仪表或副屏

1. 在设置中打开“地图投屏”，进入“选择屏幕与地图区域”。
2. 选择目标仪表或副屏，允许显示在其他应用上层。
3. 地图宽度、高度填 `0`，自动使用目标屏幕尺寸；可见地图高度填 `0`，显示完整地图。需要特殊区域时，可以填写数值或拖动预览区域的下边缘。
4. 保存后重新连接手机。开始导航后显示完整地图；开启三指飞屏后，三指上滑可以打开或收起地图。

自动模式优先使用目标尺寸，并根据硬件解码能力降低输出分辨率。显示时按比例缩放；屏幕比例与手动配置不一致时，保留空白区域，避免拉伸或裁掉地图。屏幕尺寸发生变化时，会重新调整投屏窗口；下次连接手机时重新选择自动输出尺寸。

手动填写的地图宽高保持原值。不支持该尺寸时，请改为自动模式或调小数值。

“切换原厂仪表导航模式”需要支持该车型的车辆数据桥。地图出画面后才切换仪表模式；结束投屏时恢复原来的模式。副屏直接显示地图可以独立使用。

## 音量按键或旋钮缩放

在地图按键设置中分别绑定缩放模式、放大和缩小。按键来源可以选择“车辆按键或旋钮”或“安卓通用按键”。安卓通用按键需要开启应用的无障碍服务。

地图正在显示、原厂菜单允许操作且没有通话时，缩放模式才生效。缩放期间接管已经绑定的音量按键；退出缩放后恢复常规操作。车辆接口未确认可以接管按键时，不发送缩放指令。

这些设置可用于提供相应屏幕和按键能力的车型。
