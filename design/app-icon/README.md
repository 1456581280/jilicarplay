# App icon

Minimal geometric visual, confident and calm, clear silhouette at 48px. The symbol must fit the central 60% safe area for Android adaptive masking. Full square edge-to-edge opaque background, no rounded-corner boundary baked in. No letters, no text, no car manufacturer logos, no Apple logo, no watermark, no mockup, no multiple icons, no border. Flat front view with very subtle dimensional finish, crisp clean edges.
